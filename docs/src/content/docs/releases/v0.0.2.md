## What's new

- Release binaries for **macOS**: `pkgr-macos-arm64` (Apple silicon) and `pkgr-macos-x86_64` (Intel).
- macOS joins the CI gates, so the unix terminal code is now compiled and tested on a Mac runner on every push.
- The release workflow is reorganised: a manual run is a dry run, and tags containing a `-` are published as pre-releases.

## Things you might notice

The macOS binaries are not signed or notarised, so macOS may quarantine a downloaded file. See [Install](/getting-started/install/) and [Troubleshooting](/guides/troubleshooting/). The picker has been built and tested on a Mac runner but not yet verified by hand in Terminal.app or iTerm: please report anything odd.

## Upgrading

Replace the binary. There is nothing to migrate.
