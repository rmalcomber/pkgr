**The first official release.**

[View this release on GitHub]({{releases}}/tag/v0.0.1)

## What's new

- Lists the scripts in a `package.json` or the tasks in a `deno.json`, lets you pick one and runs it with the right package manager in the right directory.
- Package manager from `packageManager`, then the lockfile, then `npm`; Deno runs `deno task`.
- Filtering picker; exit code 130 on cancel; with redirected streams it prints the tasks and exits 1.
- Linux (static musl, 116,840 bytes) and Windows x86_64 binaries with `SHA256SUMS`.
